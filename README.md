# HelloCart – PHP MVC Food Ordering Website

HelloCart is a PHP-based web application designed for online food ordering and dine-in services. Built using the Model-View-Controller (MVC) architectural pattern, it offers a structured and scalable solution for restaurants aiming to digitize their ordering process.

## 🚀 Features

- **User-Friendly Interface**: Intuitive design for easy browsing and ordering.
- **Menu Display**: Categorized food items dynamically listed from the database.
- **Cart System**: Add, remove, and update cart items before checkout.
- **Dine-In Option**: Customers can place orders for dine-in.
- **Order Management**: Basic order processing and status handling.
- **Responsive Design**: Works well across mobile, tablet, and desktop screens.

## 🛠️ Tech Stack

- **Backend**: PHP (MVC Architecture)
- **Frontend**: HTML, CSS, SCSS, JavaScript
- **Database**: MySQL
- **Templating Engine**: Smarty
- **Local Server**: Apache via XAMPP

## ⚙️ Getting Started (Local Setup)

To run the project locally using XAMPP:

1. **Install XAMPP**  
   Download from [https://www.apachefriends.org](https://www.apachefriends.org)

2. **Clone the Repository**  
   Navigate to your `htdocs` folder:
   ```bash
   cd /path-to-xampp/htdocs
   git clone https://github.com/ravirajladha/hellocart-php-mvc-version.git
   ```

3. **Import the Database**  
   - Start **Apache** and **MySQL** from XAMPP.
   - Go to [http://localhost/phpmyadmin](http://localhost/phpmyadmin).
   - Create a new database (e.g., `hellocart`).
   - Import `hellowcart2.sql` into that database.

4. **Run the App**  
   Open your browser and go to:
   ```
   http://localhost/hellocart-php-mvc-version/public
   ```
